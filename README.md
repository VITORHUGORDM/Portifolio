# Portfólio · Vitor Hugo

Meu portfólio pessoal: uma página estática (HTML, CSS e um pouco de JavaScript, sem frameworks e sem build), responsiva e acessível, com meus projetos e tecnologias.

🔗 **Site:** https://vitorhugordm.github.io/Portifolio/

## Estrutura

```
.
├── index.html    # conteúdo da página
├── style.css     # estilos (tema escuro, responsivo)
├── script.js     # menu do celular
└── assets/       # foto e imagens dos projetos
```

## Rodar localmente

Não precisa instalar nada: abra o `index.html` no navegador, ou sirva a pasta com qualquer servidor estático:

```bash
npx serve .
```
